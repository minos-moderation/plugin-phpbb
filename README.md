# Minos — moderacja postów dla phpBB

Rozszerzenie phpBB 3.3, które wysyła nowe posty do bramy Wergiliusz (usługa Minos) i stosuje
werdykt, który brama odsyła podpisanym webhookiem: publikuje post, publikuje go z
zamaskowanymi fragmentami albo zostawia w kolejce do zatwierdzenia. Rozszerzenie jest w
budowie; instrukcja instalacji i opis ustawień pojawią się w tym pliku.
